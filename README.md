# 充電守衛

獨立 Android 充電監測與保護 App，套件名稱為 `tw.com.linweijun.chargeguardian`，可與先前 App 同時安裝。

## 主要功能

- 依目前電量切換紅色（低於 30%）、綠色（30–79%）、藍色（80% 以上）主題。
- 顯示電量、電池端電壓、充電電流、已充時間與預估達標時間。
- 顯示電池溫度至小數點一位，45°C 以上發出高溫警告。
- 保護運行期間每秒重新取樣並更新畫面；電流顯示最近 5 秒平均的電池淨電流。
- 每次開始新的保護工作時，異常中斷次數自動歸零。
- 電壓警告門檻為電池端 4.65V 持續 10 秒，或 Android 系統直接回報過壓。
- 30–99% 可調目標，另有 100% 勾選框。
- 保護啟動後鎖定目標卷軸及 100% 勾選框，取消保護後才可再次調整。
- 警告提示音可設定 0–100% 相對音量，並可獨立開關震動。
- 達到保護目標時可用中文語音朗讀結果，並可獨立關閉語音。
- 前景服務持續監測；未達標斷線會累計並警告。
- 電池端電壓與溫度異常警告。
- 支援 Root 且具有相容 sysfs 節點的手機可真正斷充；一般手機以高優先通知及震動提醒拔線。

## 重要限制

Android 一般第三方 App 沒有切斷充電硬體的系統權限。App 不會把「通知拔線」冒充「已自動斷電」。真正斷充只會在 App 自動確認 Root 控制成功後顯示。

另外，Android 公開 API 提供的是電池端電壓，不是充電器 USB 輸入電壓，因此畫面與警告會清楚標示為「電池端電壓」。

## 編譯

將整個專案上傳到 GitHub，開啟 Actions，執行 `Build Charge Guardian APK`，完成後下載 `ChargeGuardian-debug-apk` artifact。
